ABC Omni-PLAY Mobile Application

Frontend and Key Feature

During my internship, I developed the Angular/Ionic frontend for a comprehensive internal employee engagement application. My main contribution was the dynamic 'PLAY' feature, designed to let employees create and join company-wide games and competitions. This platform was a crucial driver for increasing internal engagement.

Backend and Architecture

The application is powered by a secure Java Spring Boot REST backend utilizing Microsoft Entra ID and a PostgreSQL database. The backend employs a clean, layered architecture, specifically implementing the Ports and Adapters design pattern (also known as Hexagonal Architecture). This pattern is evident in the distinction between the Port (defining business interfaces) and the Adapter (implementing the interface for external tools like the Controller or Repository). I specifically chose to implement manual data mapping to ensure a deep, practical understanding of data integrity across all layers.

Testing Strategy

To ensure code quality and reliability, I implemented targeted unit and integration tests for the backend layers. Specifically, I utilized Spring Boot's testing framework along with Mockito to write Controller layer tests. These tests verify the correct handling of HTTP requests, ensuring that both successful resource retrieval (status().isOk()) and edge cases like resources not being found (status().isNotFound()) are handled correctly. Crucially, I employed Mockito's static mocking capabilities to isolate the Mapper layer during Controller tests, guaranteeing that the business logic (Service layer) and the mapping logic were correctly integrated and independently verifiable.

Virtual Drone Environment using OpeanWeatherMap API

  • C-sharp
  • Unity
  • API
  • Desktop App

Project Goal

This project aims to simulate a drone flying within a virtual sandbox environment. The environment itself is dynamic: it uses particle systems and terrain assets (like grass) that adapt in real-time based on a set geographic location. This location-specific data, such as weather and atmospheric conditions, is fetched using the OpenWeatherMap API.

Flight Mode Transition

The drone defaults to 'Auto-Pilot Mode', which enforces flight boundaries (geofencing). To fly beyond these boundaries, engage 'Manual Override'. Upon the release of manual controls, the system instantly switches back to Auto-Pilot, maintaining flight stability and re-enforcing the established box limits.
